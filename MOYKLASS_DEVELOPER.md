# Подключение CRM «Мой Класс»

Код интеграции использует [официальный API](https://api.moyklass.com/) и вебхук `user_changed`. API-ключ хранится в игнорируемом Git файле `.env` в корне проекта. В Docker Compose этот ключ передаётся backend через переменную окружения. Для других хостингов добавьте те же переменные в секреты сервиса.

Если backend работает на Render, задайте `MOYKLASS_API_KEY`, `MOYKLASS_WEBHOOK_SECRET` и `MOYKLASS_SUBJECT_MAP` в настройках **backend-сервиса**. Локальный `.env` на Render не загружается.

## 1. Создайте признаки ученика в CRM

Откройте настройки признаков **ученика**, создайте следующие поля. Алиас справа нужен коду. Если CRM сгенерирует другой алиас, укажите его в `.env` как `MOYKLASS_ATTR_ACCESS=...` и так далее; список ключей есть в `back/src/integrations/moyklassAccess.js`.

| Название | Алиас | Тип | Значение |
| --- | --- | --- | --- |
| Бот — Доступ | `bot_access` | Да/Нет (`boolean`) | Главный переключатель |
| Бот — Доступ до | `bot_access_until` | Строка | `2026-10-31T18:00:00+03:00` или `2026-10-31` |
| Бот — Тип доступа | `bot_access_kind` | Список (`select`) | Варианты `Пробный`, `Платный` |
| Бот — Предметы | `bot__predmety` | Список (`select`) | Один предмет из вариантов ниже |
| Бот — Последний вход | `bot_last_opened` | Строка | Заполняет приложение |
| Бот — Telegram ID | `bot_telegram_id` | Строка | Заполняет приложение при привязке |
| Бот — ID пользователя | `bot_user_id` | Строка | Заполняет приложение при привязке |
| Бот — Последняя синхронизация | `bot_last_sync` | Строка | Заполняет приложение |
| Бот — Ошибка синхронизации | `bot_sync_error` | Строка, необязательно | Показывает ошибку настройки |

В `bot_subjects` добавьте **Математика**, **Русский язык**, **Химия**, **Физика**. Не используйте существующий признак `predmet`: он описывает занятия с репетитором и не является разрешением на предметы Mini App.

Публичный API CRM показывает тип `date`, но не отдельный тип «дата и время». Поэтому для трёх полей с точным временем нужен тип **строка** и ISO 8601 со смещением `+03:00`. Для `bot_access_until` можно указать только дату: доступ действует до конца этого дня по Минску.

После создания полей выполните из корня проекта:

```powershell
cd back
npm run moyklass:check
```

Команда покажет реальные алиасы, типы и ID вариантов предметов без вывода API-ключа или данных учеников. Укажите эти ID в корневом `.env`, например:

```dotenv
MOYKLASS_SUBJECT_MAP={"123":"Математика","124":"Русский язык","125":"Химия","126":"Физика"}
```

ID здесь пример. Используйте значения, которые вернёт команда.

## 2. Настройте вебхук

Создайте вебхук в «Настройки → API и webhooks» с адресом:

```text
https://<адрес-backend>/api/moyklass/webhook/<MOYKLASS_WEBHOOK_SECRET>
```

В «Настройки → Сценарии» добавьте отправку этого вебхука для события **«Информация об ученике изменилась»** (`user_changed`). Периодическая сверка запускается каждые 5 минут и восстановит состояние, если событие потеряется. Не публикуйте адрес с секретом. Согласно [документации CRM по вебхукам](https://help.moyklass.com/ru/knowledge_base/art/81/cat/24/), дополнительной авторизации у входящих событий нет.

## 3. Привяжите существующих учеников

Ученик сначала открывает Mini App через Telegram, чтобы в базе появился его Telegram ID. Администратор открывает список учеников и нажимает кнопку связи с CRM в строке ученика. Введите **ID конкретной карточки ученика** из «Мой Класс». Код проверяет, что карточка не привязана к другому ученику, и записывает Telegram ID и ID приложения в CRM. Автоматического слияния по имени или телефону нет.

После привязки поля CRM управляют доступом, сроком и предметами. Для включения доступа заполните переключатель, тип, срок и хотя бы один предмет. Несогласованная конфигурация не выдаёт доступ. Пробный срок задаётся датой окончания в карточке; количество дней согласуйте с владельцем CRM. Когда все существующие ученики привязаны и проверены, установите `MOYKLASS_ENFORCE_LINKS=true`, чтобы непривязанные аккаунты не получали доступ через старую локальную выдачу.

Теги `Пробный период`, `Подписка есть`, `Бот оплачен`, `Бот не оплачен` интеграция создаёт при первой синхронизации и затем обновляет автоматически, сохраняя остальные теги карточки.

## 4. Проверка

На тестовой карточке проверьте: включение и отключение, оба типа доступа, окончание срока, продление, добавление и удаление предмета, последний вход и повторную синхронизацию после временной ошибки API. До этой проверки не переводите `MOYKLASS_ENFORCE_LINKS` в `true` для всех пользователей.
